# Adopted Style Memory

Learn how the user writes, not what happened in one case.

## Admission gate

Accept only material that the user explicitly designates as a style sample or a final version they adopted. Drafts, model outputs, copied text, and unconfirmed edits do not become preferences automatically.

## Extract

- document genre and audience;
- section sequence and paragraph function;
- sentence density, rhythm, and transition patterns;
- preferred terminology and recurring concise formulations;
- phrases the user removed or repeatedly rejected;
- provenance: source, version, adoption date, and applicable genre.

Never store names, amounts, dates, products, approvals, incidents, or other case content as style. A sentence can be a good expression sample while remaining unusable as factual evidence.

## Confidence

Mark a preference from one sample as `provisional`. Promote it to `stable` only after repeated adopted evidence or an explicit user instruction. Preserve contradictory samples instead of forcing a false preference.

## Output

Return a concise style profile with preferred patterns, avoid patterns, scope, confidence, and source references. When applying it, preserve the new document's facts and formal requirements over stylistic similarity.
