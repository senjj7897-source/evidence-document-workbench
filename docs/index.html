01 / PRODUCT THESIS

复杂材料工作，
首先需要可复核的方法。

材料越多、版本越多，越需要说明结论依据和核验范围。

没有出处的结论难以复核；没有边界的风险提示容易被误认为已发生事实；附件不全时，也不能因为暂未查出问题就视为审查完整。

Evidence Workbench 管理的不只是单份文档，而是从材料、判断到修改和采用的完整过程。

02 / EVIDENCE PIPELINE

从材料到结论，保留每一步依据。

确定性程序负责事实、计算和位置，模型负责语义判断与表达。两类结果分别记录，便于复核。

  1. 01材料快照

    保存不可变副本与哈希，锁定实际审查版本。

  2. 02审计级解析

    保留页、条、段、表、单元格、公式与修订位置。

  3. 03双层核验

    精确计算与语义审查并行，主动查找反证。

  4. 04统一问题库

    跨文档相同问题只汇总一次，证据不丢失。

  5. 05采用与复用

    只有明确采用的成果进入文风与经验资产。

03 / CORE CAPABILITIES

五项能力，不是五个孤岛。

它们围绕同一个对象工作：一件需要形成判断、交付成果并在未来复用的真实事项。

MULTI-DOCUMENT DIFF

比较“意味着什么变了”，而不只是“哪些字变了”。

先对齐对象、时期、版本和范围，再比较事实、数字、规则、责任、公式与语义。删除文字、现行文字和批注分开处理，避免把修订痕迹制造成假冲突。

  • 多版本与跨文件口径对齐
  • 文表、公式与附件联动核验
  • 相同问题跨文件聚合

04 / EPISTEMIC STATES

不是所有“问题”，确定性都一样。

FACT

直接事实

可由原文、公式、数值或内部矛盾直接证明。

OMISSION

可确认缺口

按明确检查范围搜索后，必要要素仍然缺失。

CONFLICT

待核实冲突

来源表述不同，但适用版本或权威性尚未确定。

INFERENCE

风险推断

可能产生的后果，不得写成已经发生的事件。

06 / TRUST BOUNDARY

产品价值，也来自它明确不做什么。

把边界写进产品，而不是藏在免责声明里。

01

不把“运行结束”写成“审查完整”。

02

不把“没有材料”写成“没有问题”。

03

不凭文件名和日期认定制度现行有效。

04

不把表达样本中的个案事实迁移到新稿。

05

不自动采用模型改写，也不替责任人作最终判断。

06

不把可检索正文冒充公式、修订、签章和版式证据。

TRACEABLE DOCUMENT WORK

结论有出处，修改有理由，
未确认事项有边界。
